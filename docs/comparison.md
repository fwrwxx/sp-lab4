## Сценарії специфічні для ОС (п. 7.2)
1. **Блокування шини (Інверсія пріоритетів):** `longop` тримає м'ютекс 84 мс, `sensor` пропускає семпли (`missed` 2→7).
2. **Переповнення стека:** При стеку `cmd` 96 слів виклик `TASKS` призводить до `FATAL: stack overflow`.
3. **Вичерпання heap:** При `configTOTAL_HEAP_SIZE = 2048` виникає `FATAL: malloc failed`.
4. **Вплив частоти тіку:** При `configTICK_RATE_HZ = 100` роздільна здатність таймера стає 10 мс.
